# Episode Meta Prompt

Use this prompt as the default starting point when generating podcast cover-art prompts from an uploaded episode and transcript.

## Prompt Template

```text
Create a square podcast cover for an AI OS research episode.

Episode title: [TITLE]
Core thesis: [THESIS]
Primary stakes: [STAKES]
Visual metaphor: [METAPHOR]

Art direction:
- dark navy-black background
- cinematic glass and atmospheric depth
- cyan and electric-blue glow with restrained emerald accents
- abstract systems imagery, architectural symbolism, signal paths, loops, waveforms, maps, or governance structures as appropriate
- high contrast, minimal clutter, premium research-library feel
- no stock-photo people
- no generic corporate illustration
- no warm cheerful startup palette

Composition:
- centered focal image with strong silhouette
- clean negative space for future title lockups
- subtle motion implied through lines, loops, or light trails
- consistent with AI OS shell aesthetics

Return a single cohesive cover concept, not multiple options.
```

## Prompt Construction Notes

- Replace `[METAPHOR]` with a content-specific symbol from the transcript.
- Prefer symbolic system imagery over literal scenes.
- If the episode is high-risk or cautionary, make the image feel precise and alarming, not sensational.
- If the episode is governance-focused, emphasize control surfaces, maps, contracts, boundaries, or evidence structures.
