# /rebuild

Run the production build for **this project** (AI OS voice interface).

1. In the terminal, from the repository root (`ai-os-voice-interface`), execute:

   ```powershell
   npm run build
   ```

   On Windows PowerShell, if needed:

   ```powershell
   Set-Location "C:\Apps\ai-os-voice-interface"; npm run build
   ```

2. Paste or summarize the command output for the user (success line, `dist/` assets, and any warnings).

3. If the build fails, show the error and stop; fix only if asked.

Optional: run `npx tsc --noEmit` only if the user wants a typecheck before or after the build.
