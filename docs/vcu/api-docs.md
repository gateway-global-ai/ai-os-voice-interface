## No-Mock Requirement

These sources must be used as primary references. Do not create mock lessons, mock installs, mock tests, mock triangulation, fake logs, placeholder database rows, or simulated acceptance evidence.

If a source cannot be reached or verified, the lesson/task status must be `blocked` or `unverified`.
